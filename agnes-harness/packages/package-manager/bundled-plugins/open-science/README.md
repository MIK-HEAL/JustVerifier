# Bundled research resource catalog

This package ships the Open Science Skills with Agnes Harness. The `mcp/servers.json` file records the canonical application-owned MCP service identities and tool names used by those Skills. Agnes keeps MCP connection definitions in its managed resource store; this catalog does not invent a third-party executable or copy the Open Science desktop runtime.

The Skill files are redistributed under the Apache-2.0 license from the Open Science project. See `LICENSE`.
